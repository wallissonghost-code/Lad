# LAD Store

Protótipo de loja virtual responsiva, sem autenticação ou pagamentos.

## Recursos
- Navegação por Início, Ofertas, Eletrônicos, Casa, Moda e Games
- Busca de produtos
- Carrinho com quantidade e total
- Persistência local do carrinho via localStorage
- Layout responsivo para celular e desktop
- Compatível com hospedagem estática / GitHub Pages

Abra `index.html` ou publique a branch `main` via GitHub Pages.
